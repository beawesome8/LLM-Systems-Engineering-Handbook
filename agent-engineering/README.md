# Agent Engineering

**Status: stub — not yet built.**

The design of systems where a model plans, calls tools, and takes multi-step action toward a
goal rather than answering a single turn. Covers single-agent tool-use loops, planner/
executor patterns, and multi-agent orchestration.

## Where this is already demonstrated at production scale

- [Recurring Research Agent](https://github.com/beawesome8/Recurring-research-agent) —
  multi-node LangGraph agent (planner, search, synthesis) with dual memory
- [BQ-Vertex-Analyst](https://github.com/beawesome8/BQ-Vertex-Analyst) — LangGraph-based
  Gemini/Vertex AI agent with AST-based grounding/validation gating
