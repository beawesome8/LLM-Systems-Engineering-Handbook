# Chain of Density

**Definition:** Start with a basic, sparse response, then iteratively densify it across
multiple passes — adding detail, entities, or nuance at each step — without letting the
response balloon in length. The output gets richer without getting longer.

**When to use it:** Summarization tasks where a first-pass summary is too vague and you want
to pack in more informative content (specific numbers, names, causal links) while holding
length roughly constant.

**When not to:** Tasks where a single dense pass already works, or where brevity/simplicity
is the actual goal — densification works against readability there.
